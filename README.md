# Python Bootcamp

A structured **84-learning-day Python bootcamp** focused on building real programming independence from near-zero Python experience toward problem solving, practical Python, NumPy/Pandas, and HackerRank readiness.

The long-term direction is **AI Engineering / Data Engineering**, not a Data Analyst-only path.

---

## Why this bootcamp exists

The main goal is not simply to “finish Python syntax.”

It is to change the way I work with code.

### Current pattern

```text
Problem
→ ask AI
→ AI writes code
→ read / modify output
```

### Target pattern

```text
Problem
→ reason
→ write pseudocode
→ write first attempt
→ debug
→ ask AI only when needed
→ rewrite independently
→ explain the solution
```

The bootcamp is successful only if my **independent coding ability increases**.

---

## Core learning path

```text
Programming with Python
→ Problem Solving
→ Core Python Tools
→ NumPy / Pandas
→ HackerRank
→ AI / ML / DE specialization
```

This is intentionally **not** a “Python for Data Analyst” bootcamp.

The first priority is programming fundamentals and problem solving. Data tooling comes later, after the foundation is strong enough.

---

## Duration

**Planned length: 84 learning days (12 weeks).**

This is an estimate, not a strict deadline.

A “Day” is a learning unit, not necessarily a calendar day. If a day is incomplete, the next session continues from that day before moving forward.

Typical session target:

**45–60 minutes/day**

Time is not the real completion criterion.

A learning day ends when I can:

1. explain the main concept in my own words;
2. write at least one solution independently from a blank screen;
3. correct the most important mistake made that day;
4. solve the final mandatory task with acceptable independence.

---

## Bootcamp rules

- Attempt before asking AI.
- Do not copy-paste AI solutions as my own work.
- Most exercises start from a blank editor.
- AI is used as a tutor, reviewer, and debugger — not as the default coder.
- If AI gives substantial help on an important task, rewrite the solution independently afterward.
- Do not skip fundamentals just to reach NumPy/Pandas faster.
- Do not study another new programming language in parallel during this bootcamp.
- No mandatory homework outside the learning session.
- If a concept is genuinely failed, repair it before moving on.
- Avoid turning normal sessions into unnecessary multi-hour marathons.

---

## AI help ladder

When stuck, help should escalate gradually:

1. **Self attempt**
2. **Conceptual hint**
3. **Directional hint**
4. **Pseudocode hint**
5. **Partial code / pinpoint bug**
6. **Full solution only when necessary**

If a full solution is used for an important task:

```text
Close the answer
→ open a blank editor
→ rebuild the solution independently
```

## Daily learning flow

A normal session follows roughly this structure:

```text
Quick recall
→ Learn the new concept
→ Small example
→ Guided attempt
→ Progressive practice
→ Mandatory blank-screen task
→ Review / debugging
→ Rewrite when needed
→ Close the session
```

Practice should usually progress through:

```text
Easy → Medium → Challenge
```

Daily exercises are intentionally **not fully pre-generated**. They should adapt to actual performance.

## Roadmap

| Phase | Days | Focus |
|---|---:|---|
| 1 | 1–14 | Python Survival |
| 2 | 15–28 | Core Python Data Structures |
| 3 | 29–42 | Functions + Program Decomposition |
| 4 | 43–56 | Problem Solving + Basic Algorithmic Thinking |
| 5 | 57–70 | Practical Python for Real Programs |
| 6 | 71–78 | NumPy + Pandas Foundation |
| 7 | 79–84 | HackerRank Intro + Transfer |

### Phase 1 — Python Survival

**Days 1–14**

Topics include:

- running Python and `print()`
- variables and assignment
- `int`, `float`, `str`, `bool`
- operators and expressions
- input and type conversion
- Boolean logic and comparisons
- `if / elif / else`
- `for` and `while`
- `range()`
- combining loops and conditions
- basic debugging

**Day 14:** Python Survival Checkpoint

---

### Phase 2 — Core Python Data Structures

**Days 15–28**

Topics include:

- strings
- indexing and slicing
- string methods
- lists
- list methods and iteration
- tuples
- dictionaries
- sets
- nested structures
- frequency counting
- choosing the right data structure

**Day 28:** Data Structures Mini Project + Cold Test

---

### Phase 3 — Functions + Program Decomposition

**Days 29–42**

Topics include:

- defining and calling functions
- parameters and arguments
- `return`
- local vs global scope
- functions with lists and dictionaries
- decomposition into multiple functions
- default and keyword arguments
- `try / except`
- validation
- tracebacks
- debugging strategy
- refactoring repeated logic

**Day 42:** Function-Based Program Checkpoint

---

### Phase 4 — Problem Solving + Basic Algorithmic Thinking

**Days 43–56**

Topics include:

- problem → examples → pseudocode → code
- counting problems
- min/max without built-ins
- accumulator patterns
- searching
- duplicate detection
- frequency maps
- multi-condition problems
- string traversal
- sorting concepts
- simple manual sorting logic
- nested loops
- complexity intuition
- mixed unseen problems

**Day 56:** Timed Problem-Solving Checkpoint

---

### Phase 5 — Practical Python for Real Programs

**Days 57–70**

Topics include:

- modules and `import`
- standard library basics
- file paths
- reading and writing text files
- CSV
- JSON
- organizing code across files
- virtual environments
- `pip`
- dependency awareness
- simple logging
- basic OOP
- classes

**Day 70:** Small Multi-File Program Checkpoint

---

### Phase 6 — NumPy + Pandas Foundation

**Days 71–78**

Topics include:

- NumPy arrays
- shape, indexing, slicing
- vectorized operations
- simple vector / matrix operations
- Pandas Series and DataFrame
- loading, selecting, filtering
- `groupby`
- aggregation
- missing values
- merge / join

**Day 78:** Mini Data Task

---

### Phase 7 — HackerRank Intro + Transfer

**Days 79–84**

Topics include:

- HackerRank format
- input/output patterns
- Easy Python problems
- Easy Problem Solving problems
- timed Easy set
- Easy → early Medium bridge

**Day 84:** Cold HackerRank-Style Assessment

Day 84 is not the end of Python learning. It is the first major decision point for what comes next:

- continue HackerRank;
- deepen Python;
- extend NumPy/Pandas;
- move toward ML;
- add DE-oriented Python;
- later consider C++ as a second language.

## Assessments

Assessments use a mix of:

- output prediction;
- bug explanation;
- debugging;
- blank-screen coding;
- mini-projects;
- unseen problems;
- timed problem sets.

Some major checkpoints must be completed **without AI**.

At least one checkpoint must use an unfamiliar context to test real skill transfer rather than memorization.

Scores are diagnostic, not pass/fail.

### Generic programming problems

- logic;

```text

→ structured records
→ file loading
→ validation
→ transformation

→ Pandas

```

The goal is one meaningful project that grows with the skill level, not dozens of shallow repositories.

## Success criteria

By the end of this bootcamp, I should be able to:

### Programming

- write basic Python from a blank screen;
- use conditions, loops, functions, and core data structures;
- read and fix basic errors;
- decompose a small problem;
- write multi-step programs without AI generating the first draft.

### Problem solving

- translate problems into pseudocode;
- solve common counting, string, list, and dictionary problems;
- approach unseen Easy coding tasks;
- solve HackerRank Easy problems independently.

### Python for data

- understand NumPy array fundamentals;
- perform basic Pandas loading, filtering, grouping, and merging;
- connect Python programming to future AI / data work.

### Independence

The key benchmark is simple:

> **When AI disappears, meaningful coding work can still continue.**
